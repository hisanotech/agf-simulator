# 製品倉庫の概念構造・表示契約（最新の初期交通方針を反映）

利用者が更新した配置・用途と初期交通方針を反映した**ユーザー確認済みの抽象構造**。実CAD座標、寸法、停止位置、走行距離を表さない。以前の待機・充電兼用表現を置き換え、主通路の初期方向と未確認の実車線・停止座標を分離する。

合計802PL（西598・東204）。東の列構成は9列＋空列1列＋8列。空列にはパレットロケーションを作らず、通行可否も未確定とする。ブロックの各行は独立した双方向1車線、計29行。行内の横並び通行は禁止。隣接する別行の同時進入は可能だが、近接時の減速閾値・率・占有制御は未確定。

壁と平行な主通路は**西2本・東2本、計4本**で固定し、保管ブロックと中央壁の間に置く。本数と車線数を混同しない。最新のユーザー指示により初期交通方針は**両側とも保管ブロック側を北→南、中央壁側を南→北**とする。実際の車線幅・同時通過条件、各行への実分岐位置は未確定。中央壁の自由横断は不可で、防火シャッター2か所だけが東西接続候補となる。各防火SHの通路群は双方向2車線・同時すれ違い可能として確認済みで、個別レーン方向は未確定として別管理する。保管行と設備枝・サービス枝・外通路の既存方向は維持する。倉庫通常出入口は東側。西側出入口は通常時に使用せず、東SH故障時の迂回候補を保持するが、切替条件・操作手順・物理経路は未確定。

待機・充電場所・整列機のアクセス元が既存の東側主通路であることは確認済み。個別の実分岐・停止・旋回・荷役姿勢は未確定。新しい第3の東側主通路は作らない。**初期配置はAGF1→充電場所1、AGF2→充電場所2、AGF3→HP1、AGF4→HP2**。この割当は開始時だけであり、通常帰還先の固定割当ではない。各位置を1台ずつ占有するが、初期状態はidle・初期バッテリー100%・chargerId=null・充電器占有0とする。充電場所に停止しているだけでは充電中と扱わず、充電開始条件が成立した場合だけ既存の充電器2口排他を使用する。充電場所と充電器デバイスの固定対応も推測しない。これらの設備枠は倉庫802PLに加算しない。

倉庫全体の**通常待機場所は4か所**とする。内訳はEB2南側の待機2か所（HP1・HP2）と柱前待機場所2か所（東1・西1）。AGFごとの専用待機場所は設けず、通常帰還時の優先順位は **HP1 → HP2 → 柱前東 → 柱前西** とする。帰還開始時に未占有かつ未予約の最初の場所を選び、重複選定を防ぐため選定時点から予約する。**西側の柱前待機場所はWB2の下側、WB2とWB3の間の空き領域の東寄り。東側の柱前待機場所はEB1の下側、EB1とEB2の間の空き領域の西寄り**とする。これは2026-09-29に利用者が図示した相対位置であり、ラック寸法やブロック位置を変更して確保してはならない。通常運転でタスクがなくなったAGFはパレタイズエリアに待機せず、この4か所のうち上記優先順位で選んだ空き場所へ復帰する。充電場所2か所は初期配置時を除き通常待機場所として使用しない。`WS1～4`との番号対応と柱前の厳密な停止座標は未確定である。AGFごとの専用待機場所は設けず、待機場所の優先順位は上記のとおり確定とする。

実装の正本は `src/map/warehouse-layout.mjs`。`data/reference-logical-map.json` の `warehouseLayout` を同内容で検証する。旧 `WH-E-V` / `WH-W-V` は各側の主通路群への抽象参照で、個別道路ではない。主通路4本は別IDと初期交通方向を保持するが、実分岐・停止座標が未確認のため実CAD物理探索へ自動接続しない。`WH-SERVICE` の東側主通路群への概念アクセスは確認済み、個別の実物理ノードは未登録。

UIは各行・列・段を開き、空き・使用中・予約済み・使用不可を色と記号で識別する。合成シナリオは802個の容量1の**説明用ID**にサンプル在庫を設定する。現場の正式ID・在庫の再現ではない。マップの描画座標や隣接配置から走行距離・ETA・実際の接続を生成しない。
