## 0. 完了の定義と進捗表示

| 記号 | 判定 |
| --- | --- |
| ✅ 実装済み | 対象コードと合成テストがmainにあり、CI成功を確認。実図面受入や後続工程の完了は別。 |
| 🔄 一部実装 | 一部機能・下書き・ツールはあるが、工程の受入条件は未達。 |
| ☐ 未完了 | 必要機能または受入・確認が未完了。 |
| 🔒 非公開確認待ち | 現場由来の位置、設備動作、経路などの個別レビューが必要。公開Git上で情報を捏造・公開しない。 |

**工程のチェックを完了にする条件：** 実装・自動テスト・画面／シナリオ検証・仕様上の未確定点の扱いが揃い、関連PR／CI／レビュー根拠をIssueに記載する。下書き線の作成・仮定値の入力だけでは物理走行の完了としない。
