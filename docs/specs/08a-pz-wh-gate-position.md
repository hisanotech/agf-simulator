# 08a. PZ・外通路・WH 外周シャッター位置関係仕様

**資料区分：** CAD確認済みの相対位置関係を定義する補足仕様  
**適用範囲：** PZ南側境界、外通路、WH北側境界、包装機HI/HO、PZ入口SH、PZ出口SH、WH西SH、WH東SH  
**優先順位：** 本書の内容が `08-map.md`、`09-traffic.md`、`logical-map.md`、`reference-logical-map.json`、`logical-map.svg` の旧記述と矛盾する場合は、本書を正とする。  
**実寸状態：** 相対位置関係はCAD画像で確認済み。正確なmm座標、シャッター中心、走行中心線、停止位置、開口幅は未確定。

---

## 1. 目的

PZ・外通路・WHの外周シャッターについて、旧資料に残っていた「西側入口」「東側出口」「同一南北軸」といった曖昧な表現により、実装上でPZ入口SHとPZ出口SHを近接配置したり、WH西SHを建屋西端に配置したりする誤解が発生した。

本書では、CAD図で確認できる**相対位置関係と役割だけ**を明確化する。未確認の実座標や距離は推測しない。

---

## 2. 物理境界

CAD上の赤線は、壁等の**明確な物理境界**として扱う。

- PZ南側境界と外通路の間は、確認済みのPZ入口SH／PZ出口SH以外からAGFが横断してはならない。
- WH北側境界と外通路の間は、確認済みのWH西SH／WH東SH以外からAGFが横断してはならない。
- 防火SH2か所はWH内部中央境界上の設備であり、外周シャッターと混同しない。

概念：

```text
北

PZ内部
────────────── PZ南側物理境界 ──────────────
      PZ入口SH                          PZ出口SH

                    外通路

────────────── WH北側物理境界 ──────────────
       WH西SH                            WH東SH
WH内部

南
```

※ 上下のシャッターを完全な同一X座標として示した図ではない。

---

## 3. 包装機HI／HOとPZ入口SH

包装機のAGF停止位置は別々に扱う。

- `HI`：包装機搬入口
- `HO`：包装機搬出口

設備列の確認済み相対順序は次のとおり。

```text
PGW8 → PM1 → PGW7 → PM2 → PGW5 → PM3 → PGW4
     → HI → 包装機 → HO → PGW2 → PM4 → PGW1 → PGW3 → PM5 → PGW6
```

**PZ入口SHは、包装機搬出口HOのほぼ正面・南側に存在する。**

```text
        包装機
      HI      HO
               │
               │  南
               ↓
           PZ入口SH
               │
             外通路
```

PZ入口SHを次のように解釈してはならない。

- PZ建屋の西端入口
- パレタイザエリア西端のシャッター
- 「西」という名称だけを根拠にした最西端配置

既存の論理IDに `W` 等が含まれていても、それを物理的な建屋西端の意味として扱わない。

---

## 4. PZ出口SH

PZ出口SHはPZ入口SHとは**別の開口**である。

CAD上の相対関係として、次を確定事項とする。

- PZ南側境界上に存在する。
- PZ入口SHより東側に存在する。
- **PZ入口SHのすぐ隣ではなく、入口から明確に東へ離れた別開口である。**
- 設備列との相対関係では、**PGW1～PGW3側の南面**に位置する東側開口として扱う。

概念：

```text
西                                                     東

… PGW4   HI  包装機  HO  PGW2  PM4  PGW1  PGW3  PM5  PGW6
                    │                    │
                    │                    │
                PZ入口SH             PZ出口SH
```

この図は相対関係を示すものであり、正確なX座標・距離・縮尺を示さない。

以下は禁止する。

- `PZ出口SH = PZ入口SHの直近` とする配置
- 入口と出口を同一開口として統合
- HO正面付近へ入口を移したことを理由に、出口まで同じ周辺へ寄せる
- 旧「east gate」等の名称を根拠に、現在のPZ出口SHを削除する

---

## 5. WH西SH／WH東SH

WH北側境界には、WH西SHとWH東SHの2つの別開口が存在する。

ここでいう「西」「東」は、**2つのWH外周開口同士の相対順序**を表す。

次の意味ではない。

- WH西SH = 製品倉庫建屋の西端
- WH東SH = 製品倉庫建屋の東端

相対関係は次のように扱う。

- WH西SH：PZ入口側に対応する西側開口
- WH東SH：PZ出口側に対応する東側開口

```text
PZ側
      PZ入口SH                         PZ出口SH
          │                                │
          │           外通路               │
          │                                │
       WH西SH                           WH東SH
WH側
```

CAD上で上下の開口群は対応する位置関係にあるが、**完全な同一X座標・同一南北軸とは確定していない。**

---

## 6. PZとWHの建屋位置

製品倉庫全体は、PZに対して**東側へオフセット**している。

```text
PZ
┌──────────────────────────────┐
└──────────────────────────────┘

            WH
            ┌────────────────────────────┐
            └────────────────────────────┘
```

ただし、建屋全体の東オフセットとシャッター位置を混同しない。

特に、WHが東へオフセットしていることを理由に、WH西SHを建屋西端へ置いてはならない。

---

## 7. 通常時の外通路動線

### 7.1 WH → PZ

通常進入は次の関係とする。

```text
WH東SH
  ↓
外通路
  ↓
PZ入口SH
  ↓
PZ内部
```

PZ入口SHはHO正面付近にあるため、WH東SHから外通路を通って**PZ入口SHへ最短の有効経路で向かう。**

以下は禁止する。

- PZ入口SHの位置を一度通過する
- さらに西へ進む
- 折り返してPZ入口SHへ戻る

### 7.2 PZ → WH

通常退出は次の関係とする。

```text
PZ出口SH
  ↓
外通路
  ↓
WH東SH
```

PZ入口SHを通常退出用として使用しない。

---

## 8. 同一南北軸に関する扱い

PZ出口SHとWH東SHは、通常退出側の対応する東側開口である。

ただし、以下は未確認である。

- 完全な同一X座標
- 真南への一直線走行
- `straight-south` と断定できる幾何関係

したがって、論理資料・データ・テストで次を確定値として持たない。

- `eastReturnAxis` による物理同軸保証
- `relation = straight-south` による実配置断定
- PZ出口SHとWH東SHのX座標一致を必須条件とするテスト

「東側の対応開口」という**相対関係**だけを保持する。

---

## 9. 旧名称の扱い

次の旧表現は、物理配置を示す語として使用しない。

- パレ西入口SH
- 西側入口
- west palletizing gate
- PZ入口 = west edge
- PZ-W-IN の `W` を建屋西端と解釈する説明

また、旧資料にある `obsoleteEastGate` 等の語は、現在CADで確認済みのPZ出口SHとは別物であることが明確でない限り、削除・非表示の根拠に使用しない。

現在CADで確認済みのPZ出口SHは現行設備として保持する。

---

## 10. 確定事項／未確定事項

### 10.1 確定事項

- CAD赤線は壁等の物理境界。
- PZ南側境界にPZ入口SHとPZ出口SHが別々に存在する。
- PZ入口SHはHOのほぼ正面・南側。
- PZ出口SHは入口から明確に東へ離れた別開口。
- PZ出口SHは設備相対位置としてPGW1～PGW3側の南面にある。
- WH北側境界にWH西SHとWH東SHが別々に存在する。
- WH西SH／WH東SHの名称は建屋端を意味しない。
- WH西SHはPZ入口側、WH東SHはPZ出口側に対応する。
- WH全体はPZに対して東側へオフセットしている。
- 通常進入はWH東SH→外通路→PZ入口SH。
- 通常退出はPZ出口SH→外通路→WH東SH。
- 防火SH2か所はWH内部中央境界上にある。

### 10.2 未確定事項

- 4つの外周SHの正確な中心座標mm
- 各SHの開口幅
- AGF停止位置
- 実走行中心線
- 実旋回点
- 上下の対応SH間の正確なX差
- PZ出口SHとWH東SHが完全同軸かどうか
- 実車体クリアランス
- 実距離・実ETA

未確定事項をsynthetic値で補完しても、それをCAD実測・現場確定値へ昇格させない。

---

## 11. 実装・テストへ要求する最低条件

本書を根拠にした実装では最低限、次を保証する。

1. PZ入口SHとPZ出口SHを別ノード・別開口として扱う。
2. PZ入口SHはHO近傍に配置する。
3. PZ出口SHは入口直近へ置かず、PGW1～PGW3側の東側開口として表現する。
4. WH西SHを建屋西端へ配置しない。
5. WH東SHをPZ出口側の対応開口として扱う。
6. PZ出口SHとWH東SHの完全X一致を必須にしない。
7. 入口／出口のラベル・シャッター表示が重ならない。
8. WH東SH→PZ入口SHで入口通過後の折返しを発生させない。
9. PZ出口SH→WH東SHの通常退出経路を維持する。
10. `metricScaleVerified=false`、`physicalEtaAllowed=false` を維持し、未確認の実寸を主張しない。
