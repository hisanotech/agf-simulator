## 2. 目的と範囲

- 4台のAGF、製品パレット、空パレット、設備状態と搬送01～05を、同一時間軸の**離散イベント**で再現する。
- 3時間を初期再生範囲とし、イベントログと設備状態に基づく2Dリプレイを提供する。
- 「エリア優先あり／なし」の2方式を**同じ生産入力・初期状態**で比較する。
- 搬送要求、割当、空走、荷受け、実搬送、荷下ろし、包装・ラベル、補充、充電、倉庫入庫の順序関係を検証する。
- 実機PLC、WCS、RCSへの送信、実設備の安全判断、性能保証は対象外。
- **シミュレーターの設備配置・通路・シャッター・保管区画はCAD図のレイアウトに準拠**させる。現在の抽象論理マップ／模式図を実CADと一致した完成図とは扱わない。

## 3. 基準シミュレーション設定

| 項目 | 値 | 扱い |
| --- | --- | --- |
| AGF | 4台 | 確認済み |
| 充電器 | 2台 | 確認済み |
| 初期バッテリー | 各100% | シミュレーション初期値 |
| 消費基準 | 走行・荷役の稼働6時間で70ポイント | 供給元想定を利用者が共有。時間の対象範囲はユーザー確認済み |
| 旧1搬送消費 | 1～2%、代表1.5% | 旧シナリオ再現用。初期設定は時間基準へ変更 |
| 充電開始／通常搬送復帰 | 40%以下／80% | シミュレーション設定 |
| 充電速度 | 1%=2.4分 | シミュレーション設定 |
| パレタイザ | 8系列・各系列2PLバッファ | 確認済み |
| 01生成 | PLC搬出完了信号 | 確認済み |
| 8系列の初期搬出間隔 | GWI 17.2 / GWII 36.5 / GWIII 36.5 / GWIV 22.9 / GWV 25.3 / GWVI 21.5 / GWVII 36.5 / GWVIII 36.5 min/PL | 設備能力から算出した理論パレット排出タクト。シミュレーション初期値として使用 |
| 包装機 | 1台、投入1PL・回収2PL | 確認済み |
| 包装タクト | 3.3分/PL（18PL/hr表記と丸め差あり） | 基準条件 |
| マガジン／整列機 | 各5台・開始時は全機10枚装填済み | 確認済み |
| 03発生／補充 | マガジン残3枚で補充必要。在荷10枚の整列機がある場合のみ03発行。投入完了時+10PL | 確認済み |
| 仮置き場 | 3か所、04・05共通 | 確認済み |

実際のパレット搬出時刻と系列配分は入力イベント列で決定する。初期値には設備能力100%を前提とした理論パレット排出タクトを使用するが、これを実績PLC履歴として扱わない。**シミュレーションに用いる設定値は設定画面から変更可能**にする。**8系列それぞれの搬出頻度（間隔）は分単位で個別設定可能**にし、設定値によって生成したイベントは実PLC実績と区別する。初期値は GWI 17.2、GWII 36.5、GWIII 36.5、GWIV 22.9、GWV 25.3、GWVI 21.5、GWVII 36.5、GWVIII 36.5 min/PL。全8系列が同時に理論タクトで生産した瞬間最大は約17.8PL/hr、24時間継続時の理論出来高合計は428PL/日。実績最大出来高は約250PL/日であり、理論値と区別する。

### 3.1 基準Runの初期状態

基準Runは完全なニュートラル状態から開始する。開始前から存在する搬送タスク、予約、製品仕掛、包装中パレット、仮置きパレット、製品倉庫在庫、設備異常、充電中状態を持ち込まない。例外として、空パレット系設備は運転開始条件としてマガジン5台を各10枚、整列機5台を各10枚装填済みとする。AGFは既存の確定初期位置・初期100%を維持する。

## 5. 共通のイベント処理規則

イベントは `timeMs`（非負整数）＋ `sequence`（同時刻内の安定順序）で一意に処理する。パレットID・タスクID・設備ID・AGF ID・位置IDを引き継ぎ、以下を独立したイベントとして残す。

1. 設備による製品搬出、空パレット消費、作業者の手動指示。
2. 搬送要求の生成、実行可能車両の選定と割当。
3. 空走、停止・荷役許可、荷受け、実搬送、荷下ろし、タスク完了。
4. 包装開始／完了、ラベル完了、出口到達／搬出OK、倉庫入庫。
5. マガジン補充必要、整列機在荷、03発行、整列機10→0、整列機手動補充、マガジン補充完了。
6. 充電要求、充電位置移動、充電待ち、充電開始／終了。

イベント前提が未成立なら進めず、保留・拒否理由を記録する。AGF1台の二重割当、パレット重複搬送、設備容量超過、許可のない荷役を許容しない。

## 6. 搬送間の依存関係

```text
製品搬出 ──→ 01 ──→ 包装・ラベル・出口OK ──→ 02 ──→ 倉庫入庫
               └──→ 例外時は仮置き ──→ 04 ──→ 包装・ラベル・出口OK ──→ 02
                                          └──→ 05 ──→ 倉庫入庫（受入条件確認）
空パレット消費 ──→ マガジン残数3枚 ──→ 03 ──→ 10PL補充実績
```

02は「必ず01のみを前工程とする」のではなく、04から再投入したパレットも、必要な包装・ラベル・出口OKを満たせば対象とする。05の未包装品の受入可否等は**未確定**であり、無条件に許可しない。

## 7. 画面と入出力

- 上部：再生／停止／速度／時刻スライダー／シナリオ／選定方式切替。
- **設定画面：** シミュレーションの設定値を変更できる。系列1～8ごとの搬出頻度を分単位で別々に設定し、Runの入力条件として保持する。整列機は個別補充と全機一斉補充を手動操作できる。
- **04・05の操作：** 画面のボタンから手動で対象パレット・仮置き場・搬送先を指定してタスクを予約する（対象の在荷・許可・二重予約を検証する）。
- 中央：簡易2D設備図、AGF1～4の色付き番号アイコン、設備占有、搬送・停止状態。
- 側部：バッファ数、整列機搬送OK、マガジン残数、充電器占有、AGF位置・タスク・残量。
- 下部：時刻付きイベント履歴、パレットIDの工程追跡、AGFタイムライン、CSV。
- **結果出力：** イベントCSVとは別に、Run開始時に固定したシミュレーション条件サマリーを画面表示し、別CSVとして出力する。設備初期状態、AGF選定条件、各系列の搬出頻度、包装機の搬出／処理時間、AGF速度・充電条件、実パレット種類の排出パターン、製品倉庫の系列レイアウトを含める。
- 比較：同じ外生入力で両方式を独立実行し、入庫、要求／完了、待ち、滞留、空走、充電待ち、稼働率を並列集計する。
- 実測／確認済み設定／仮定／未確定を画面・CSVで区別する。アニメーションの時計で工程の完了時刻を独自変更しない。

## 8. 配置・経路の取扱い

**シミュレーターの最終表示・経路はCAD図のレイアウトを順守する。** 設備・荷役・倉庫保管位置は外部レイアウトデータで表現する。表示・経路・停止点・確定区分の詳細は[全体マップ仕様書](08-map.md)と[経路指定ガイド](../route-annotation-guide.md)を参照する。実図・実座標はこの公開文書に含めない。走行線、個別シャッター停止点、系列ごとの荷受け停止点は未確定。交差点・曲がり角の旋回点は仮設定に限る。未確定エッジは仮表示とし、実距離・確定所要時間や安全判断に流用しない。

## 9. 受入条件

- 01はPLC搬出完了以前に生成しない。
- 02は対象PLの包装・ラベル・出口搬出OKが成立する前に生成しない。
- 03はマガジン残3枚で補充必要状態を成立させ、在荷10枚の整列機がある場合だけ発行する。全整列機が空なら03を発行しない。整列機は荷受け完了で0枚となり、手動補充で10枚へ戻る。
- 各設備の設定容量、車両1台1タスク、充電器占有上限を守る。
- 04・05は作業者の対象指定を記録し、仮置きの同一PLを二重搬送しない。
- 同じ入力・シードなら同じイベント履歴を生成する。シーク後も履歴と表示状態が一致する。
- 仮定データを実測・確定結果として表示しない。
- 設定画面からシミュレーション設定値を変更でき、系列ごとの搬出頻度を分単位で個別設定できる。
- 04・05は対象を指定してボタンからタスク予約できる。重複・許可不足の要求は無条件に発行しない。
- シミュレーション結果をCSV出力でき、どのRun・設定条件の結果か追跡できる。
- **AGFの通常選定は目的地（荷下ろし先）エリアにいる実行可能な車両を優先し、その中でバッテリー残量が少ない車両を優先する。** 詳細は[AGF仕様](07-agf.md)。

## 10. 実装状況・未確定

公開用の開発ブランチでは、目的地エリア優先選定・シナリオ駆動の離散イベント生成・01～05の合成モデル・充電・日本語画面・イベント再生・比較・CSVを実装した。系列別の搬出間隔初期値は2026-10-01提示の理論パレット排出タクトを用いる。初回搬出ずらし、初期AGF位置、倉庫ロケーション、工程時間など他のデモ値は**合成・仮定値**であり、実PLC記録や設備実績ではない。実CAD準拠配置、実走行経路と所要時間、シャッター・車線占有・干渉制御、設備連携、実設備での性能保証は未実装である。詳細は [ハーネス契約](../harness-contract.md) を参照する。未確定事項は [決定待ち一覧](../open-decisions.md) で別管理する。

2026-09-25の倉庫配置更新は[倉庫概念契約](../warehouse-layout-contract.md)を正とする。802PL、主通路西2本・東2本、待機2か所と別の充電2か所。個別主通路の方向等は未確認。UIのローカル実装範囲は[ダッシュボード](../ui-dashboard.md)を参照。
