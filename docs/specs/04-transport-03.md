# 04. 通常搬送03 仕様書 v1.0

**独立仕様書**／関連：[全体](00-overview.md)・[設備](01-equipment.md)・[AGF](07-agf.md)

## 1. 目的・対象

空パレット残数が補充閾値に達したマガジンへ、搬送OKの空パレット整列機から一山を補充する。補充要求と整列機の準備状態、AGFの搬送、マガジンへの実投入は別イベントとする。

| 項目 | 仕様 |
| --- | --- |
| タスクID | 03 |
| 搬送元 | 搬送OKの整列機（5台から選択） |
| 搬送先 | 補充要求中のマガジン（5台から対象を指定） |
| 発生契機 | 対象マガジンの残数が**3枚になった遷移** |
| 搬送量 | **一山10PL** |
| 完了条件 | 残数確認・投入許可後の10PL投入実績 |
| 起点への移動 | AGFの**現在位置 → 整列機 → マガジン** |
| 供給元対応 | 固定1対1ではない |

## 2. 入力データ

`taskId`, `magazineId`, `magazineQuantity`, `refillPending`, `alignerId`, `alignerReady`, `alignerPermission`, `magazinePermission`, `agfId`, `refillBatch`。初期残数／最大容量／個別設備位置／搬送時間は別シナリオで設定し、未確認値を固定しない。

## 3. 処理フロー

1. パレットマガジンで空パレットを実際に払い出し、残数を更新する。
2. 残数が**ちょうど3枚に達し**、未処理の補充要求がない場合に03要求を一度生成する。
3. 作業者が10PLを準備し、搬送OKを入力した整列機から供給元を選ぶ。
4. 実行可能なAGFを割り当てる。エリア優先ありでは、荷下ろし先である対象マガジンの目的地エリアにいる実行可能AGFを優先する（最新の利用者確認済み共通選定仕様）。
5. AGFが現位置から整列機へ空走し、荷受け許可を確認する。
6. 10PL荷受け完了で整列機の搬送OK・在荷を更新し、二重引当を防止する。
7. AGFが対象マガジンへ実搬送する。
8. 投入直前にマガジン残数を問い合わせ、投入許可と受入条件を確認する。
9. 10PL投入完了の実績を登録し、そこで初めてマガジン残数を+10する。
10. 補充要求中フラグを解除し、AGFを解放する。

## 4. 状態遷移

`REQUESTED → WAIT_SOURCE_READY → ASSIGNED → MOVING_EMPTY → WAIT_PICKUP_PERMISSION → PICKING → MOVING_LOADED → WAIT_REFILL_PERMISSION → REFILLING → COMPLETED`。供給元がない場合、マガジンの投入許可が出ない場合、設備異常、AGF不足は理由付きで保留する。

## 5. 在庫・占有の規則

- 「残数3枚」という状態を毎秒評価して新規03を増殖させない。
- マガジンの在庫減算は実際の空パレット払い出しイベントによる。製品01要求の発行だけで機械的に減算しない。
- 整列機の搬送OKは作業者操作の結果であり、単なる時間経過で成立させない。
- 整列機の同じ10PLを別の03に重複引当しない。
- 補充量+10は**投入完了後**。投入許可が出た段階ではまだ加算しない。
- マガジン上限未確定時は満杯可否を断定せず、確認不能の旨を記録する。

## 6. 出力・履歴

`requestedAt`, `magazineId`, `quantityAtRequest`, `alignerId`, `readyAt`, `agfId`, `pickedAt`, `quantityBeforeRefill`, `permissionAt`, `completedAt`, `quantityAfterRefill`, `waitReason`。補充遅延、供給元待ち、許可待ち、空パレ不足を区別して集計する。

## 7. 受入条件・未確定

- 残数3枚到達時に要求を1件のみ生成する。
- 搬送OK前の荷受け、投入許可前の荷下ろし、完了前の+10を拒否する。
- AGFの二重割当、整列機の二重供給、マガジン残数マイナスを拒否する。
- **未確定：** 初期残数、マガジン最大容量、供給元選択の詳細な優先順位、荷役・走行時間。
