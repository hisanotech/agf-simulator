# 02. 通常搬送01 仕様書 v1.1

**独立仕様書**／関連：[全体](00-overview.md)・[設備](01-equipment.md)・[02搬送](03-transport-02.md)・[AGF](07-agf.md)

## 1. 目的・対象

パレタイザの搬出完了した製品パレットをAGFで包装機の投入側へ搬送する。各系列の搬出、情報紐付け、設備許可、AGF荷役を別状態として記録し、包装工程に引き渡す。

| 項目 | 仕様 |
| --- | --- |
| タスクID | 01 |
| 搬送元 | 対象パレタイザ系列の荷受け点 |
| 搬送先 | 包装機投入側の01荷下ろし点 |
| 起動トリガー | **PLC搬出完了信号** |
| 対象 | 製品パレットID（系列・製品情報と紐付け） |
| 完了 | 包装機への荷下ろし完了・投入実績 |
| 系列バッファ | **各2PL** |
| 搬出間隔の初期値 | **GWI 17.2 / GWII 36.5 / GWIII 36.5 / GWIV 22.9 / GWV 25.3 / GWVI 21.5 / GWVII 36.5 / GWVIII 36.5 min/PL**。設備能力100%から算出した理論値で、実績値ではない |

## 2. 前提・入力

`palletId`, `lineId`, `plcDischargedAt`, `productDataStatus`, `sourceReady`, `sourcePermission`, `wrapperInputAvailable`。各系列の位置・荷受け停止点、空走時間、荷役所要時間はシナリオ入力。個別位置は未確定。


## 2.1 搬出頻度の基準

シミュレーションの系列別搬出間隔の初期値は、2026-10-01提示の「パレット排出タクト」を使用する。これは設備が絶えず供給・プロセス・排出を継続できる稼働率100%前提の理論値であり、実績の平均周期ではない。

| 系列 | 理論パレット排出タクト (min/PL) | 理論物流量 (PL/hr) | 実態の最短払出頻度 (PL/hr) | 24h理論出来高 (PL/日) |
| --- | ---: | ---: | ---: | ---: |
| GWI | 17.2 | 3.5 | 3.1 | 84 |
| GWII | 36.5 | 1.6 | 1.6 | 39 |
| GWIII | 36.5 | 1.6 | 1.6 | 39 |
| GWIV | 22.9 | 2.6 | データ無 | 63 |
| GWV | 25.3 | 2.4 | 2.3 | 57 |
| GWVI | 21.5 | 2.8 | 2.7 | 67 |
| GWVII | 36.5 | 1.6 | 1.4 | 39 |
| GWVIII | 36.5 | 1.6 | 1.5 | 39 |

全8系列が同時に理論タクトで生産する場合の瞬間最大は約17.8PL/hr、24時間理論出来高は合計428PL/日。実績の出来高最大は約250PL/日であり、理論値とは分けて扱う。

「実態の最短払出頻度」は過去に最も早く払い出された局面の実績参考値であり、長時間継続する値ではない。確認済みの継続上限は最大約90分である。通常の初期シミュレーション値にはこの実績最短値ではなく、上表の理論パレット排出タクトを使用する。将来、瞬間最大負荷のストレス試験を行う場合は別シナリオとして扱い、通常Runと混同しない。

## 3. 処理フロー

1. 対象系列の生産タイミングで、対応する空パレットマガジンの残数を確認する。残数1枚以上なら空パレットを1枚払い出して残数を1減らし、その空パレットをパレタイザへ供給する。0枚なら実パレットを生成・搬出せず、01要求も発行しない。
2. パレタイザが供給された空パレットに製品を積載して実パレット化し、搬出完了後にPLC完了信号相当のイベントを記録する。対象パレットのRFID／製品情報の照合・紐付け状態を保持する。
3. 01要求を生成し、同一パレットの重複要求を抑止する。
4. AGF選定方式・優先順位により実行可能なAGFを割り当てる。
5. AGFを現在位置から系列の荷受け点へ空走させる。
6. 荷受け位置に到着後、設備側の荷受け許可を確認する。
7. 荷受け完了時に系列バッファの該当パレットを減算し、AGF積載に切り替える。
8. 包装機入口の現在パレット数＋有効予約数が入力容量未満で、受入許可がある場合だけ入口を予約する。満杯・予約済み・受入不可の場合は、個別PGW荷受け停止点の合成待機領域で積載とタスクを保持する。最初の有効出発方向へ停止旋回を済ませて待機し、待機中に繰り返し旋回しない。
9. 入口予約取得に加え、前方レーン・合流競合領域の空き、自車横で例外追い越しが行われていないことを確認して包装機へ出発する。荷下ろし完了時に予約を実パレット占有へ置き換える。
10. 1PLの投入バッファへ荷下ろしし、AGF積載を解除する。
11. 01完了を記録し、同じパレットIDで包装機処理へ引き渡す。

## 4. タスク状態

`REQUESTED → QUEUED → ASSIGNED → MOVING_EMPTY → WAIT_PICKUP_PERMISSION → PICKING → MOVING_LOADED → WAIT_DROPOFF_PERMISSION → DROPPING → COMPLETED`。設備保留・異常・キャンセル・復旧は別状態で保持し、完了と混同しない。

## 5. 他仕様との連携

- **包装機入口待ち：** `waiting_wrapper_input` は一般の通行待ちと区別する。顧客結果では「包装機入口待ち」と表示し、保存状態がその待機状態だった時間だけを履歴・タスク待ち時間へ計上する。停止旋回・予約後の通行待ち・追い越し完了待ちはそれぞれ旋回・通行待ちに分類し、入口待ちへ二重計上しない。入口容量と予約は、車両受入上限による搬送割当予約とは別に管理する。入力枠の満杯は入口に実パレットがある状態、予約済みは別の搬送がその枠を確保した状態であり、包装処理中だけで入口満杯とはしない。
- **包装機保持容量（2026-10-02利用者確認）：** 入口と出口の受け渡しは各1か所・1PL。内部コンベアは処理中を含め5PLを保持できる。内部保持と受け渡し枠を別在荷として管理し、5PL同時包装とは解釈しない。合成モデルでは包装処理は1PLずつ、内部は包装前・処理中・ラベル／排出準備・出口待ちを追跡する。内部への受け渡し所要時間・設備内の厳密な位置は未確認のため追加所要時間を捏造せず、同一時刻のイベント順で内部受入を記録する。
- **通過領域：** 個別PGWの待機はPZ共有走行領域の両レーンを塞がない。合成設備前領域を明示し、実CADの停止位置・車体寸法・実クリアランスは未確定のまま保持する。
- **限定例外追い越し：** 正規レーンを塞ぐ停止中の01包装機入口待ちAGFに限り、発進予定がなく、正規経路が使えない場合に明示済み追い越しPlanを使用できる。開始部・反対レーン区間・側方競合部・復帰部を一括予約し、対向の正規AGFが走行または予約中なら追い越し側が待つ。追い越し後は明示復帰点から正規経路へ戻る。Planがない場合は経路を捏造しない。通常走行・一般通行待ち・充電待ちには適用しない。
- **発進排他：** 包装機入口待ち車が入口予約を取得しても、側方の追い越しが完了し競合資源が解放されるまで発進しない。

- **設備：** 系列バッファは荷受け完了まで占有、包装投入は荷下ろし完了時に占有する。
- **AGF：** 車両1台1タスク、空走・実搬送とバッテリーを追跡する。
- **02：** 01完了だけで02は生成されない。包装、ラベル、出口搬出OKを経て02が生成される。
- **例外：** RFID等の異常時は別の仮置き処理を記録する。通常の01完了／02発生として扱わない。

## 6. 出力・履歴

`taskId`, `palletId`, `lineId`, `agfId`, `requestedAt`, `assignedAt`, `pickupAt`, `dropoffAt`, `completedAt`, `waitReason`, `status`。タスクの要求数・完了数・待ち時間・各系列の滞留を集計する。

## 7. 受入条件・未確定

- PLC搬出完了以前に要求しない。同じパレットを二重割当しない。
- 許可なし荷受け／荷下ろし、系列2PL・包装投入1PLの容量超過を拒否する。
- 荷受け前に系列バッファを減算しない。荷下ろし前に包装機へ投入しない。
- 01完了後も、包装工程が終了するまでは02を要求しない。
- **未確定：** 8系列の個別停止点、区間別空走／荷役／搬送時間、RFID異常からの具体的復旧方法。
