# 03. 通常搬送02 仕様書 v1.2

**独立仕様書**／関連：[全体](00-overview.md)・[設備](01-equipment.md)・[01搬送](02-transport-01.md)・[04搬送](05-transport-04.md)・[AGF](07-agf.md)

## 1. 目的・対象

包装機の出口から対象製品パレットを荷受けし、指定倉庫ロケーションへ搬送・入庫する。先行する01または04と、包装・ラベル・出口搬出可能の工程履歴を同一パレットIDで追跡する。

| 項目 | 仕様 |
| --- | --- |
| タスクID | 02 |
| 搬送元 | 包装機回収側の02荷受け点 |
| 搬送先 | 製品ごとに指定された個別倉庫ロケーション |
| 発生条件 | **包装完了、ラベル貼付完了、出口到達・搬出OKが全て成立**。同一行に既存置きタスクがある場合は発行保留 |
| 完了条件 | 指定ロケーションへの荷下ろし完了・入庫実績 |
| 出口受渡枠 | **1か所・1PL**。内部コンベア保持5PLと別管理 |
| 包装タクトの基準 | **3.3分/PL**。ラベル・移送時間と混同しない |

## 2. 前提・入力

`palletId`, `upstreamTaskId`（01または04）, `wrapped`, `labelCompleted`, `exitReady`, `destinationLocationId`, `destinationAvailable`。倉庫のロケーション選定根拠、段積み・容量条件、走行時間は外部シナリオで定義する。格納先の個別座標は未確定。

## 3. 処理フロー

1. 01または04で包装機へ引き渡された対象パレットを受け付ける。
2. 包装処理を開始・完了する。
3. 対象パレットのラベル貼付完了を確認する。
4. 出口到達と搬出OKを確認し、対象のロケーションと所属する横1行を確認する。
5. **同じ行に既存の置きタスクがある場合は新規02を発行しない。** 対象PLと保留理由を保持し、既存の置きタスク完了後に再判定する。
6. 同じ行に置きタスクがなければ、ロケーションの空き・予約状況・受入可否を確認する。利用可能なら**02発行時に当該ロケーションを予約**し、同じパレットIDで02要求を登録する。予約不可なら発行待ちを継続する。
7. 実行可能なAGFを割り当て、包装機出口へ空走させる。
8. 荷受け許可のもと荷受けし、回収バッファから対象パレットを除く。
9. 指定倉庫ロケーションまで実搬送する。
10. 荷下ろし完了後にロケーション在庫を登録し、02を完了する。

## 4. タスク・設備状態

タスクは `REQUESTED → ASSIGNED → MOVING_EMPTY → WAIT_PICKUP_PERMISSION → PICKING → MOVING_LOADED → WAIT_STORAGE_PERMISSION → DROPPING → COMPLETED`。包装側の工程状態は `WRAPPING → WRAPPED → LABELED → EXIT_READY` と分ける。包装完了だけの状態では02を生成しない。

## 5. 例外・保留

出口受渡枠が満杯なら、包装済みパレットを内部コンベアで保持し、02荷受け完了による出口の解放まで新たな出口受渡を保留する。内部保持は処理中を含め5PLまでとし、内部待機のパレットを出口到達済みとして02発行しない。出口搬出OK未成立、ラベル未完了、同じ行の既存置きタスク、倉庫ロケーション未指定・満杯・予約済み、走行区間通行不可、AGFなしの場合は、理由付きで待機する。**02発行待ちの対象はAGFに割り当てない。**空きがないからといって架空の倉庫完了を記録しない。手動ラベル・異常復旧の具体手順は未確定。

入口・出口各1か所・各1PL、内部コンベア保持5PLは2026-10-02利用者確認。旧出口2PLモデルは明示的な回帰テスト用Scenarioに限り残し、基準Runの仕様とは区別する。

## 6. 出力・履歴

`palletId`, `upstreamTaskId`, `wrapperCompletedAt`, `labelCompletedAt`, `exitReadyAt`, `requestedAt`, `agfId`, `pickedAt`, `storedAt`, `destinationLocationId`, `waitReason`。入庫数は**02/05の入庫完了実績**から集計し、02要求数と混同しない。

## 7. 受入条件・未確定

- 同一パレットの包装・ラベル・出口OKが揃わない02を拒否する。
- 01または04からの引渡しと02のパレットIDが一致する。
- 荷受け完了前に回収側の在荷を消さず、荷下ろし完了前に倉庫在庫を増やさない。
- 出口受渡1PL、内部コンベア保持5PL、倉庫の個別容量、AGF占有を守る。
- 同じ行の置きタスクが完了するまで新規02を発行しない。02発行時に搬送先ロケーションを確認・予約し、二重予約を防ぐ。行全体の物理占有開始時刻や05への同じ発行ルールの適用は未確定。
- **未確定：** 個別倉庫位置、格納ルール、ラベル・出口移送時間、積み付け・段積みの処理時間。
