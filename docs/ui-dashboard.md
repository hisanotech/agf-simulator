# ローカルダッシュボードの実装範囲

2026-09-25のデザイン指示と更新済み倉庫仕様を反映。ローカル `main` 上の確認用変更で、今回のコミット・Push・PR作成・公開は行わない。

| 画面 | 実装内容 |
| --- | --- |

通常・追加仕様の倉庫行割当と優先順位は、ユーザー指定により既存の合成検証例と同じ値を初期表示する。根拠は`user-requested-example-default`として保存し、実CAD位置・経路の承認とは区別する。編集と未割当行は引き続き許容する。系列→マガジンの固定対応は対応表待ちで、推測値を初期設定しない。

「設定を反映して実行」またはヘッダーの実行・比較で設定エラーが出た場合は、設定画面の該当カテゴリを開き、問題の入力欄まで自動スクロールしてフォーカスする。赤い入力枠、行の背景、カテゴリの「要確認」、理由文、`aria-invalid`／`aria-describedby`で識別する。再計算に失敗した場合は以前のRunを保持し、エラーを隠してモニターへ戻らない。

再生は `requestAnimationFrame` で表示時刻だけを1・2・4倍で進め、最後の `timeMs <= 表示時刻` のイベントの保存スナップショットを描画する。同時刻の全イベント適用後を使い、未来の結果を途中時刻へ混入しない。先頭への停止、シーク、次イベントへの移動でもシミュレーションを再計算しない。**再生機能の受入はコード存在・構文チェックだけでは不可とし、実ブラウザで▶押下後に時計・シーク値・AGF表示位置が連続更新され、一時停止・停止・倍率変更・次イベント移動が動作することを確認する。**

設定変更は明示的な実行まで保存済み結果へ反映しない。実行失敗・予約エラーでも前の結果を保持する。手動操作は表示時刻に入力を追加した候補シナリオを計算し、成功した場合だけ置き換える。二重予約、場所不一致、未許可、入庫先を確保できない場合は拒否理由を表示する。未反映設定がある間は、先に実行するよう案内する。

分析は各スナップショットの継続時間を実行終了まで積分する。graphモデルでは空走・積載走行・停止旋回・荷受け姿勢移行・荷受けフォーク挿入後・荷下ろし姿勢移行・荷下ろしフォーク挿入後を排他的に分類する。旧モデルの単一荷役時間は勝手に分割しない。作業稼働率はこれらの作業時間を実行期間で割り、充電・充電移動・待機場所復帰・交通待ち・設備待ちを含めない。包装機入口待ちは専用に測定し、顧客向け大分類では設備待ちに含める。充電場所への出発前の空き待ちは充電待ちに含め、生の状態別時間を別途保持する。別内訳を合計へ再加算しない。

顧客向け完了件数は正式な `TASK_COMPLETED` イベントだけを基準にする。AGF4台の完了数合計、搬送01～05の完了数合計、総完了数は一致させ、各AGFの5種類の小計もそのAGFの完了数と一致させる。充電回数は `CHARGE_STARTED` の発生回数だけを数える。初期充電場所への停止・充電場所への移動・充電待ち・充電器予約は充電回数に含めない。最終電池残量は終了スナップショットから小数1桁で表示する。未完了理由は「包装機入口待ち」「通行待ち」「AGF割当待ち」等の日本語とし、生の理由コードを主画面へ出さない。発進前の旋回中等にタスクへ古い待機理由が残っていても、保存されたAGFの実際の状態を優先し、「旋回中」「搬送中」「荷役中」「通行待ち」と表示する。専用の停止待機状態では「包装機入口待ち」とする。

顧客向け時間表は移動・荷役・旋回・待機・通行待ち・設備待ち・充電・充電待ち・設定等の待ちへまとめ、各AGFの合計が実行時間と一致するよう0.1分単位の端数を配分する。集計元のミリ秒は丸めない。発行前の02保留はタスク数と分け、詳細な稼働率・タイムライン・区間設定・保存Scenarioは開発者向け詳細に残す。

CSVはすべてUTF-8 BOM付き。顧客向けの「シミュレーション条件CSV」「搬送実績CSV」「AGF別実績CSV」を別ファイルとして結果画面から出力する。ヘッダと条件値の意味は日本語にし、条件CSVは `区分,項目,対象,値,単位,根拠` とする。搬送実績は要求・正式完了・未完了を区別し、AGF別実績は搬送別小計・最終残量・充電開始回数・充電時間を保持する。未反映の編集設定を出力へ混ぜない。

開発・再現確認用の詳細イベントCSVと詳細条件CSVも維持する。詳細イベントCSVは保存済み結果の全イベント、実行識別子、方式、元／先、状態、根拠区分、先頭行のScenario JSONを含む。包装機入口予約・内部受渡し・例外横通過の対象AGF／資源／未確定時間根拠も記録する。内部受渡しの追加所要時間は未確認のため、同時刻のイベント順による因果記録を実測0秒と扱わない。

詳細条件CSVはRun開始時に固定した完全な設定値を出力し、再生時刻やRun終了時の状態変化で内容を書き換えない。最低限以下を含める。

- Run ID、シナリオ名／版、選定方式
- 設備初期状態：マガジン各10枚、整列機各10枚、包装機・各バッファ・許可／異常の初期条件
- AGF選定条件：エリア優先有無、残量優先、fallback、待機場所優先順位
- 各系列の搬出頻度：GWI～GWVIIIのinterval／offset
- 包装機の搬出／処理時間としてRunで使用した設定値
- AGF速度：空走・積載・充電移動・待機復帰で使用した速度設定
- AGF充電：初期残量、消費モデル、充電開始閾値、充電終了目標、充電速度、充電器数
- 実パレット種類排出パターン：系列ごとの普通満載／普通端数／特注満載／特注端数のON/OFF・間隔・offset
- 製品倉庫系列レイアウト：ブロック・行・系列／SPECIAL／未割当・行優先順位

画面上の条件サマリーと条件CSVは同一の保存済みRun設定から生成し、イベントCSVとは独立して確認できるようにする。

通常シナリオの停止旋回角速度は12.1deg/sを暫定初期値にする。公開カタログの旋回半径1.424m・積載旋回速度0.3m/sから導出した等価角速度であり、実測停止旋回角速度ではない。荷受け姿勢移行0.25分・フォーク挿入後荷受け0.10分・荷下ろし姿勢移行0.25分・フォーク挿入後荷下ろし0.15分も暫定シミュレーション値と明示し、旋回中の電池消費は初期設定で含める。設定変更を保存したRunでは実際に使用した値・根拠を表示し、空欄にした値は補完せず必要な処理を保留する。

包装機は入口・出口の個別停止点が各1か所、受渡枠が各1PL、内部コンベア保持容量が5PL。内部表示は包装処理中を含む保存済み内部配列を1回だけ数え、入口・出口保持数と別表示する。投入予約中は他AGFの荷下ろし枠を確保している状態であり、包装処理中だけで入口満杯とはみなさない。搬送01の荷受け後は包装機入口を予約できるまで個別PGW前で包装機方向へ停止旋回して待機し、積載とタスクを保持する。待機中AGF以外の通過可能領域を残し、明示経路と排他予約のある場合だけ包装機入口待ちAGFの例外横通過を認め、正規方向へ復帰する。反対レーン使用中・復帰先使用中・姿勢移行中は横通過できない。通常の追い越しは禁止。旧回帰シナリオの内部容量未指定モデルは明示的に残す。

PZは同一走行可能空間内の交通制御上の2レーンで、初期方針は南側が西→東、北側が東→西。レーン変更は明示Node/Edgeを使用し、両端だけの人工的接続制約・入口直後の共通左迂回を設けない。倉庫主通路は東西とも保管ブロック側が上→下、中央壁側が下→上。保管行の双方向1車線と、防火SH通路群の双方向2車線・個別レーン方向未確定は維持する。条件表示は保存された通行方針を読み、旧Runへ新方針を上書き表示しない。

電池の初期設定は走行・荷役360分で70ポイント消費。供給元の想定を利用者が共有し、対象時間はユーザー確認済み。待機・荷下ろし待ち・充電待ちを除外し、充電場所への移動を含める。画面のイベント間の残量は保存状態と経過時間から共通の純粋関数で求める。旧タスク単位方式も明示選択でき、CSVには方式・根拠・時間範囲と設定値を保持する。稼働率では充電移動を別集計するが、電池消費時間には含める。詳細は[AGF仕様](specs/07-agf.md)。

構造・設備用途は[倉庫の概念契約](warehouse-layout-contract.md)の確認値。倉庫行の系列色はマップと倉庫詳細ダイアログで共通化し、GWI～GWVIII・SPECIAL・未割当を凡例付きで識別できるようにする。未割当行は配置候補にしない。通常帰還先はAGF固定ではなく、HP1 → HP2 → 柱前東 → 柱前西の順で空き場所を選定する。在庫、保管位置ID、初期AGF位置、搬出のずらし、移動・荷役時間等は明示した合成／仮定値。ただし系列別搬出間隔の初期値は2026-10-01提示の理論パレット排出タクトを使用する。標準・充電競合・手動予約の3つの再現可能なデモを用意する。充電競合デモは初期41%、系列1〜4が60分間隔、系列5〜8停止、初回ずらし0分。容量上限を守りながら2口の充電待ちを発生させるための合成入力である。

実走行位置・姿勢、選択AGFの物理経路ハイライト、距離別消費、実シャッター信号、交通占有・衝突回避、実機のボトルネック分析は未実装。概念通路は破線で表示し、承認済み実経路は未登録と明示する。CAD上へ仮のAGF位置を重ねず、M3〜M8の完了を主張しない。

検証：`npm run check`。追加回帰は802位置・空列除外・待機／充電枠の分離・禁止区画、同時刻シーク、倍率・終端、状態継続時間、同一入力比較、予約エラー時の不変性を対象とする。**CIのNodeテストとUI構文チェックが成功しても、ブラウザ再生確認が未実施なら再生を「完了」と判定しない。** PC／狭い画面で、▶再生、時計進行、AGF移動、一時停止、停止、シーク、倍率変更、次イベント移動を実操作し、結果と画面証跡をローカルの非公開レビュー領域に保存する。
